Upload#

Upload local files to an Upload location in the Organization bucket.

upload() asks the platform file proxy for temporary S3 credentials that can only write under uploads/<location>/, then writes each file with boto3. An Ingestion spec reads the files with the returned location as a location path.

Without overwrite, every write is conditional (If-None-Match: *), so a file that already exists is refused and counted as skipped. Running the same upload again therefore resumes it at file level. A large file is sent as a multipart upload and is refused only at the end, after its parts are sent again.

iter_files(input_dir: Path, exclude: list[str] | None = None) → Iterator[Path][source]#

Recursively yield files under input_dir, skipping directories.

Parameters:

  • input_dir – Directory to walk recursively.

  • exclude – Optional list of glob patterns; any file whose path matches a pattern is skipped.

Yields:

Each file path that survives the exclude filter.

upload(client: PrescientClient, local_dir: str | PathLike, location: str | None = None, *, pattern: str | None = None, overwrite: bool = False, on_file: Callable[[int, int, Path], None] | None = None) → str[source]#

Upload the files under local_dir to an Upload location.

Each file is written to uploads/<location>/ followed by its path relative to local_dir, so a spec pattern that selects the local files selects the uploaded ones too.

Without overwrite, a file that already exists in the location is skipped, so you can run an interrupted upload again to finish it. The credentials last at most one hour; the SDK asks for new ones before they expire, so a long upload keeps working.

Example:

location = upload(client, "/data/scenes", pattern=r".*\.tif$")
# Use ``location`` as a location ``path`` in an Ingestion spec.
Parameters:

  • client (PrescientClient) – The signed-in client. The caller needs the ingest permission in their Organization.

  • local_dir (str | os.PathLike) – Local directory to scan recursively.

  • location (str, optional) – The Upload location to write to: 1 to 4 /-separated segments of lower-case letters, digits, ., _ and -. When omitted, the platform creates a new one.

  • pattern (str, optional) – Regex applied with re.match to each file’s forward-slash path relative to local_dir, as the Ingest API selects source files. When omitted, every file is uploaded.

  • overwrite (bool) – Replace files that already exist. Defaults to False.

  • on_file (Callable[[int, int, Path], None], optional) – Called after each file with (index, total, path) where index is 1-based. Useful for progress display.

Returns:

The Upload location, for a location path in an Ingestion spec.

Return type:

str

Raises:

  • FileNotFoundError – If local_dir does not exist.

  • requests.HTTPError – If the file proxy refuses to issue credentials, for example 403 without the ingest permission or 422 for an invalid location.

  • botocore.exceptions.ClientError – If S3 refuses a write for any reason other than an existing file.
