Ingest Resources#

High-level resource classes built on top of IngestClient.

These wrap an ingestion (and its batches) as stateful Python objects with a small observer hook so external code can react to state changes. Construction goes through the classmethods create / from_id / from_number so the network call is visible at the call site.

For a live, auto-updating Rich progress display, wrap a resource in LiveStatus — display lifecycle lives there, not on the resource.

class BatchResource(client: IngestClient, model: Batch)[source]#

A single ingestion batch as a stateful Python resource.

Construct via create() (POST a new batch under an ingestion) or from_number() (attach to an existing batch). Most users will get a BatchResource back from IngestResource.create_batch(). Wrap in LiveStatus for a live progress display.

class IngestResource(client: IngestClient, model: Ingestion)[source]#

A Prescient ingestion as a stateful Python resource.

Construct via create() (POST a new ingestion) or from_id() (attach to an existing one). Wrap in LiveStatus for a live progress display:

ing = IngestResource.create(client, spec="spec.yaml")
with LiveStatus(ing):
    ing.wait_until_ready()
    if not ing.errors():
        ing.start().wait_until_done()
classmethod create(client: IngestClient, spec: IngestSpec) → IngestResource[source]#

POST a new ingestion from spec and wrap the result.

Parameters:

  • client (IngestClient) – Client used for the API call and subsequent state transitions.

  • spec (IngestSpec) – The specification to submit. A IngestSpec is serialized to YAML and submitted, but only after checking that every location is an s3:// path — the Ingest API cannot read local paths.

Returns:

A resource wrapping the newly created ingestion.

Return type:

IngestResource

Raises:

ValueError – If spec is an IngestSpec with one or more locations still pointing at a local (non-s3://) path. Upload those sources first (see IngestSpec.with_uploaded_sources).

class LiveStatus(resource: _IngestResource, *, console: Console | None = None, refresh_per_second: int = 4)[source]#

Render a live, auto-updating Rich display of a resource’s status.

Wraps any IngestResource or BatchResource. Use as a context manager — the display starts on __enter__, refreshes after every refresh() and start() on the wrapped resource, and finalizes on __exit__. The resource itself remains fully usable outside the block (without the live display):

ing = IngestResource.create(client, spec="spec.yaml")
with LiveStatus(ing):
    ing.wait_until_ready()
    if not ing.errors():
        ing.start().wait_until_done()
class _IngestResource(client: IngestClient)[source]#

Shared state + observer machinery for IngestResource and BatchResource.

Subclasses cache a pydantic model, expose status/listings, and notify registered observers each time the model changes (via refresh() or start()). The class is intentionally display-agnostic — wrap it in LiveStatus to get a Rich live progress display.
