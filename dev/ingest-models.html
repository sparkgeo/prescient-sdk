Ingest Models#

Pydantic models for the Prescient Ingest API.

These mirror the schemas defined in the Ingest API OpenAPI specification and are returned by prescient_sdk.ingest_client.IngestClient.

pydantic model Batch[source]#

A single batch within an ingestion, including its lifecycle timestamps.

Fields:

  • batch_number (int)

  • created (datetime.datetime)

  • finalized (datetime.datetime | None)

  • id (int)

  • ingestion_id (int)

  • started (datetime.datetime | None)

  • status (prescient_sdk.ingest_models.Status)

field batch_number: int [Required]#
field created: datetime [Required]#
field finalized: datetime | None [Required]#
field id: int [Required]#
field ingestion_id: int [Required]#
field started: datetime | None [Required]#
field status: Status [Required]#
