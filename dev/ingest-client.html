Ingest Client#

Client for the Prescient Ingest API.

class IngestClient(client: PrescientClient | None = None, organization: str | None = None)[source]#

Client for the Prescient Ingest API.

Wraps the REST endpoints of the multi-tenant ingestion service and returns typed pydantic models. Every request goes through client.session, which sends a fresh bearer token and retries once after a 401.

The base URL is <prescient_endpoint_url>/ingest/.

Parameters:

  • client (PrescientClient, optional) – The client to send requests with. When None, a PrescientClient() is built from the default settings (environment variables and config.env). Build a PrescientClient yourself to use other settings. Defaults to None.

  • organization (str, optional) – The Organization to act in. Only a super admin, whose token belongs to no Organization, needs it; it is sent as the organization query parameter on every request. Anyone else may only name their own Organization. Defaults to None.

create_ingestion(spec_file: Path | str | bytes) → Ingestion[source]#

Create a new ingestion from a version 2 ingestion spec YAML.

Parameters:

spec_file (Path | str | bytes) – The YAML spec. A Path or str is a file path. bytes is sent as the file content; encode an in-memory string with .encode("utf-8") first.

Returns:

The new ingestion.

Return type:

Ingestion

Raises:

  • IngestSpecError – If the API rejects the spec (400), for example a wrong version, a user field, or an External destination that is not publicly readable.

  • CollectionOwnershipError – If the spec’s collection belongs to another Organization (409).

  • IngestAPIError – For any other error response, for example 403 when the caller is not an admin of the Organization.
